\# Chocolate Sales Analysis Dashboard



\## Project Overview

An interactive sales analysis dashboard created using Microsoft Power BI to explore chocolate sales, product performance, and sales trends.



\## Tools \& Technologies

\- Microsoft Power BI

\- Power Query

\- DAX

\- Data Cleaning

\- Data Visualization



\## Key Analysis Areas

\- Overall sales performance

\- Sales by product and category

\- Sales by country or region

\- Sales trends over time

\- Top-performing products and salespeople

\## Project Objectives

\- Compare product and regional performance.

\- Support data-driven sales decisions.
